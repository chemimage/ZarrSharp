# ZarrSharp

ZarrSharp is an attempt to fully translate the `zarr-python` reference implementation to
C# with GPT-5.4 and curated with human review.

Further details around API differences, intentional deviations, and reference similarity
notes will be documented here over time.

## Examples

See the [examples](examples/) folder and
[examples/README.md](examples/README.md) for reference-style dataset generation
and Python readback/interoperability checks.
